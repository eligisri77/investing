# Trading Pulse — התקנה (למשתמש)

**לא צריך git.** מורידים קובץ אחד ומתקינים.

## שלב 1 — התקנה

1. הורד `TradingPulse-Setup-*.exe`
2. לחץ פעמיים — האשף בעברית
3. קרא את מסך המידע → **הבא** → **התקן**
4. מומלץ: סמן «הפעלה אוטומטית עם Windows (tray)» אם רוצים שהסוכן ירוץ ברקע
5. בסיום — האפליקציה תיפתח (אייקון גם ב-tray)

ההתקנה **לא דורשת מנהל** — מותקן תחת תיקיית המשתמש.

## שלב 2 — בוט טלגרם

1. באפליקציה: **🤖 חיבור בוט** (או הגדרות)
2. צור בוט ב-@BotFather → העתק Token
3. שלח `/start` לבוט שלך
4. קבל Chat ID (@userinfobot)
5. **הגדרות** → הדבק → **בדיקת חיבור** → **שמור בוט**

## שלב 3 — שימוש

- בערב (~21:00) תגיע תוכנית בטלגרם
- אשר עם `הכל` (חלוקה אוטומטית ממזומן)
- אם יש מזומן פנוי — הבוט מציע גם לחזק החזקה קיימת עם `תקנה`
- או אשר בדשבורד: **תוכנית פעילה**

## איפה הנתונים שלי?

```
C:\Users\<שם>\AppData\Local\TradingPulse\
  config.json
  .env
  data\
```

גיבוי = העתקת התיקייה הזו.

## הסרה

Windows → Settings → Apps → Trading Pulse → Uninstall

לאחר ההסרה תופיע הודעה: **קבצי התוכנה נמחקים**, אבל תיקיית הנתונים למעלה **נשארת** (גיבוי). מחקו ידנית אם אין צורך.
