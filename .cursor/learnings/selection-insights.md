## Method2 vs RS/VCP (מסוכם)

| | Method2 | RS / VCP |
|--|---------|----------|
| דוגמאות | DOCU, LMT, PATH, GTLB, BYND, URA, ARM, MRNA, BB, ELF(M2)… | ELF, SNOW, TWST, ESTC, EAT, ARKG… |
| תוצאה | W5/L11 · ~−$83 | RS ~+$56 · VCP +$13 |
| «סימן טוב» | תבנית נרות + ציון גבוה | חוזק יחסי / כיווץ + רצפה רחבה |
| סטופ | לרוב צר (~1.5–4%) | ~8–9% |

מסקנה: ב־Method2 «סימנים יפים» = איכות **נר**, לא בהכרח איכות **מגמה**.

2. Fill תוך־יומי / פריצה ואז היפוך

## המלצות לכללים (לאישור לפני מימוש)

ממוין לפי חוזק ראיות אחרי שבועיים:

1. **מומלץ ראשון:** מינימום סטופ Method2 מול ATR (או רצפת % מוחלטת ~2.5–3%) — לדחות סטאפ צר מדי.  
2. **מומלץ שני:** להוריד `method2_max_offers` ל־1 **או** להקטין `method2_risk_pct` — פחות חשיפה עד שהסטופים מתוקנים.  
3. **אופציונלי:** הגבלת שעת fill Method2 מאוחר.  
4. **אופציונלי:** רף backtest ל־Method2.  
5. **לא דחוף:** מסנן score אחרי `ret_5d` חם (מדגם קטן).

**חלופה חזקה ופשוטה:** לכבות זמנית `method2_enabled` בהגדרות ולתת ל־RS/VCP/score לרוץ לבד שבוע — מדידה נקייה.
